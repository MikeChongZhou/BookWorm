# BookWorm 1.0.5：本地读听与下载

## 已实现的行为

打开书籍不再被后台云同步的 busy 状态直接忽略。读取 PDF 原件前显示打开提示，TXT／EPUB 解析和书库 JSON 编解码在 isolate 中执行。进度保存使用小型 position 文件；正文仅在新增、迁移或内容变化时写入。旧的“章节 · 2”连续分段合并为完整章节，按原段起点转换位置；原件存在时补取旧 EPUB 的封面。

播放会话由音频服务持有，退出阅读页仍可听书，书架与下载页保留迷你播放器。系统中断和拔耳机暂停，锁屏本身只触发进度保存。iOS／Android 使用 audio_service、audio_session 和真实音频播放时间；Melo 使用本地 ONNX，iOS 系统音色使用原生 AVSpeechSynthesizer 完整输出 PCM16 WAV，最终缓冲到齐后才交播放器。Android 系统音色使用平台文件合成。macOS 系统语音仍使用原生朗读回调，Windows 接入 audio_service_win 系统媒体控制；未经验证的平台不声称验收通过。

锁屏媒体信息包含书名、章节、封面（可用时）、章节进度、播放／暂停及前后 20 秒命令。系统锁屏面板的具体排布由操作系统决定。音频进度查询采用独立定时器，不依赖 Flutter 界面刷新帧。

听书页顺序为封面、章节、定时／声音／语速、前后 20 秒与章节时间轴、原文／上一章／播放暂停／下一章／目录。章节总时长在未全部生成前标为“预计”；已生成片段使用实际音频时长。Melo 和文件系统语音可在当前生成片段内按音频时间恢复；未生成内容的时间定位依赖估计，不能声称整章未生成时已有精确逐字对齐。

原文页分页、句级灰色高亮、跟随朗读定位。点击当前朗读句暂停；左／上为上一页，右／下为下一页。点击其他区域显示播放、目录、本地笔记、自动翻页、颜色与字号工具栏。字体、纸张和字体颜色保存在本机，笔记不公开也不上传。自动翻页在应用后台和弹层覆盖时让出。

## 下载与每日作业

主导航为书架、听书、下载、设置。下载页读取文硕阁明确发布的公版 CSV 目录和 Standard Ebooks 的公开分页书库；不访问授权 OPDS，不追踪任意页面链接。书源的公版范围由来源方标注，Standard Ebooks 依美国范围；地区差异在下载页说明。

首次在线获取目录，以后按本机自然日检查一次；ETag 条件请求与磁盘目录缓存避免重复拉取，离线仍可搜索缓存。搜索、上下浏览和 EPUB 下载直接进入本地书架。单文件传输限制内存与带宽占用，解析在 isolate 中完成，损坏／失败下载不覆盖现有书籍。Standard Ebooks 官方 HTML refresh 下载跳转经过同源 EPUB 路径校验。

私人云自动同步按每个云、每台设备每天至多一次尝试，保留手动同步。失败不每分钟重试。读书或后台听书开始后，云传输在文件块边界安全让出；未发布 manifest 的半成品不会成为另一设备的书籍。目录扫描也让出，回到空闲时继续。

当前没有云端常驻调度服务。每日检查在应用有运行机会时完成，应用完全退出、无网络或被系统限制后台时，在下次打开／恢复后补做；不保证关闭应用后仍在固定时刻完成扫描。

## 验证记录

- 静态分析无问题；33 项常规回归通过，3 项需要本地大模型／指定 EPUB／网络的测试默认跳过。
- 用户指定的本地《红楼梦》EPUB：1,361,441 bytes，122 个目录项（含前言／目录及 120 回），884,795 字符，封面 21,932 bytes；解析 208ms，主线程心跳仍运行；最长章分页 31ms（测试字体），10 次进度保存 12ms，书库读取 20ms。正文在保存进度后保持不变。设备实测时间并非四端性能承诺。
- 真实目录扫描 7,887 本：文硕阁 6,341，Standard Ebooks 1,546；真实下载《论语》与 A Fighting Man of Mars，均可导入和离线读取。
- iOS 模拟器真实系统语音连续测试约 90 秒，音频位置推进 85.5 秒，暂停与前后 20 秒命令通过；此轮记录未进入后台，不能据此声称真机锁屏已验收。
- Mike Backup iPhone 的正常应用 1.0.5（6）：用户选择系统 TTS 后确认“持续播放，锁屏控制正常”，真机熄屏／锁屏控制验收通过。Melo 熄屏、Windows 原生构建／真机及 Android 熄屏仍需分别核验。

每次上传 GitHub 前升级应用版本号与构建号；当前源码版本 1.0.5+7。构建 7 修复旧 EPUB 章节迁移和自动同步弹窗，iOS 开发 IPA、Android 调试 APK 与签名 macOS ZIP 已重新生成，文件名明确带 build7。手机仍保留已验收的构建 6；TestFlight 尚未上传。
