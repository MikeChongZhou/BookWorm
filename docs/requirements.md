# BookWorm／书虫：第一阶段需求

版本：0.3 · 2026-11-14
状态：按用户明确收敛的范围实施，不再等待整体商业版本批准。

## 当前范围

1. 四端 App：iOS、Android、Windows、macOS，保持核心流程一致。
2. 本地导入个人电子书，阅读和 TTS 听书，无会员或平台购书门槛。
3. 同步本人书籍和读听位置，私人云支持 OneDrive、iCloud、Google Drive。
4. 书籍与进度按普通文件保存，**不加密**；云授权令牌仍用系统安全存储，避免泄露账号访问权。
5. 私人数据只在本机及用户授权的私人云；不设书虫内容中转服务器。
6. 公共书库、管理员上架、版权交易、借阅、购买、5%／95% 分成及商业 DRM 本阶段不做。
7. 不做真人有声书、公开评论、点评或社交。既有个人数据保留，不在重构中自动删除。

0.2 的商业远景保存在 [历史需求](requirements-v0.2.md)；其加密、公共书库、交易与待确认门槛不再约束当前第一阶段。

## 导入、阅读和听书

- 文件：第一轮支持 UTF-8 TXT、无 DRM EPUB 文字／章节、PDF 原版式及文本层提取。单文件上限 50 MB，PDF 最多 2,000 页。
- EPUB 本轮不是完整图文排版引擎，按 spine 读取正文和标题；图片、复杂 CSS、公式等不作为已经实现的能力。
- 重复文件按 SHA-256 判断，保留原进度；原始来源文件不改写，导入副本与解析内容保存在应用支持目录。
- 书架搜索、目录、书内检索、前后节跳转、阅读字号及夜间模式。
- TXT／EPUB 长章节切成有界文字小节；进度以小节及字符偏移保存，不以滚动百分比估算。
- 设备 TTS 分段朗读、暂停续播、上下节、语速、系统音色、定时停止及本节结束停止。
- 读听使用同一字符位置；选择文字可调整听书起点。PDF 原版页与提取文字视图可切换，听书使用对应页文本。
- 扫描 PDF 无文本层时仍可看，不假装可以听；OCR 暂不做。第三方 DRM 不破解，异常文件明确报错。
- 本地进度定期保存、暂停或退出阅读时刷新，旧原型书籍迁移后保留原 SharedPreferences 数据作为恢复来源。

## 私人云同步

- OneDrive、Google Drive 使用用户自己的应用专用区域；iCloud 采用用户自己的 CloudKit private database，非公共数据库。
- 本人四端登录相同云应用／同一云账号，以一个主云同步书籍与进度；第一阶段不做三云双向镜像。
- 文件先分块上传并校验，最后发布清单；下载未完整或校验失败不提交到本地书架。
- 每台设备独立保存进度文件，另一设备的不同位置提示用户选择，不能静默覆盖本机位置。
- 打开／恢复 App、阅读返回书架、在书架停留期间及手动操作触发同步。OS 未允许后台执行时不承诺持续实时同步。
- 云撤权、配额不足、网络失败或缺块时保留本机文件，给出错误和重试路径。
- 本机移除不删除云副本，下次同步会取回；界面明确说明。全云删除与跨云迁移完整工具暂不做。
- 云 API 开发者注册、各端 client ID、回调 URL、Google 项目配置与 CloudKit schema 是真实接入前提。未配置安装包不能宣称已能登录同步。

## 验收

- 单元／组件：TXT／EPUB 解析、持久化与迁移、损坏文件保留、TTS 暂停位置、同步传递及损坏分块拒绝。
- 四端分别编译、验证导入与系统 TTS；Windows 在 Windows 主机或 CI 验证。
- 三种云分别做四端真实授权、同源书籍传递、读听进度冲突、断网及撤权测试；模拟云测试不替代这些验收。
- 记录后台、锁屏、媒体键与来电行为；未完成的原生播放能力不得标记已支持。
- 第一阶段不要求部署平台后端，不购买第三方服务，不将尚未配置的云连接标记“完成”。
