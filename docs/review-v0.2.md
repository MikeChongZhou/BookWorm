# BookWorm／书虫：需求与设计确认清单

版本：0.2（整体方案待确认）
日期：2026-11-14
文档：[产品需求](requirements.md) · [系统设计](system-design.md)

## 已由用户确认，无需重复确认

- 名称 BookWorm／书虫；iOS、Android、Windows、macOS。
- 私人导入无会员听书门槛，私人书籍仅本地／本人云，在本人四端 App 间传递；进度通过私人云同步，读听位置协调。
- 首批私人云 OneDrive、iCloud。
- 公版免费阅读／听书／下载；版权书提供借阅／购买。
- **扣除税费、渠道费后的净收入：平台 5%，版权方 95%。**
- 不设借阅数量、数字副本库存及续借次数上限；每次续借按版权方定价，允许免费。
- 默认自动下载，支持离线，App 管理的电子书默认加密，版权书不提供明文导出。
- 普通人购得电子书或纸书不取得公共上架资格；公共书库只能为版权方有效授权版本或经核实公版。
- 当前仅管理员上架；版权方提供授权和价格材料，不因此获得自助发布权限。
- 当前不支持真人有声书；评论、点评、个人评分只保留本机，不公开、不上平台、不自动进私人云。
- 当前先确认文档再开发；账户额度剩余 ≤5% 停止规则继续有效。

## 本轮已修改的系统设计

1. 拆分私人数据域、公共书库与交易域；私人正文、书目和进度不进入平台服务器。
2. 将 OneDrive／iCloud 做成客户端直连连接器；iCloud 的 CloudKit 私人库与 iCloud Drive 区分，非苹果端专项验证。
3. 移除库存／预约／借阅配额；加入报价快照、零元借阅、每次续借订单、购书恢复、签名离线许可。
4. 加入税费／渠道费明细、实际净收入分成、平衡账本、退款冲正、版权方对账与出款。
5. 加入默认加密下载、私人库恢复密钥、设备授权、公版通用格式免费导出与防盗版技术边界。
6. 移除真人音频、公开评论和普通用户公共上架流程；个人点评与可同步笔记分开建模。

## 对“默认加密”的解释

默认加密管理缓存不等于修改用户已经持有的原始文件。版权内容不提供 App 明文电子书出口；公版仍可免费导出通用格式。客户端需要解密片段来显示／朗读，不能承诺破解设备、内存抓取或拍照完全不可复制。

这一边界已写入需求与测试门槛，不能用“绝对防盗版”作为无法证明的验收结果。
