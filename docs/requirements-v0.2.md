# BookWorm／书虫：产品需求文档

版本：0.2（已纳入用户修订，整体方案待确认）
日期：2026-11-14（America/Detroit）
配套：[系统设计](system-design.md) · [确认清单](review.md) · [实际进度](PROGRESS.md)

## 1. 产品目标与已确认原则

BookWorm，中文名“书虫”，是 iOS、Android、Windows、macOS 四端阅读与听书 App。以微信读书的读听体验为参考，采用独立品牌、私人数据架构和按书交易模式。用户本次明确要求优先于 0.1 草案及“其他全部对齐”的笼统表述。

以下为用户已确认的需求，不再作为待选建议：

1. 私人导入支持阅读和听书，不因未购买会员、未在书虫购书而限制听书。
2. 私人书籍仅存本人本地或本人私人云，能在本人各平台书虫 App 间传递；不得上传书虫平台书库或进入公共发现。
3. 首批私人云为 **OneDrive、iCloud**；阅读进度通过私人云跨端同步，并协调阅读和 TTS 听书的位置。
4. 公版书籍不收费，可阅读、听书、下载；有版权书籍提供借阅和购买选项。
5. 借阅、购买收入扣除税费与渠道费后，按 **平台 5%、版权方 95%** 分配。
6. 不设数字副本库存、不设借阅数量上限；续借次数不限，每次按版权方设定计费，版权方可设为免费。
7. 书籍支持离线阅读，默认自动下载本地，App 内电子书默认加密保存；版权书不提供明文电子书导出。
8. 已购其他电子书或拥有纸书，不产生公共上架资格。公共内容只能是版权方有效授权的版本，或经核实的公版版本。
9. 当前只有管理员可执行公共上架，普通读者和版权方均不获得自助上架入口；管理员代录版权方授权和定价。
10. 当前不支持真人有声书。书籍评论、点评不公开，只保存在读者本地。
11. 本轮仅修订需求与设计，待用户确认后继续功能实现。任一适用账户额度窗口剩余 ≤5% 时停止，见根目录 AGENTS.md。

本文是目标规格，不是实现完成声明。0.1 的“仅借阅、5 本上限、续借一次、预约队列、默认在线、真人音频、公开评论、平台同步私人书籍”等相冲突内容全部作废。

## 2. 参考基线与本期边界

参考核对日期：2026-11-14。[微信读书官网](https://weread.qq.com/)用于核对搜索、分类和发现；[腾讯发布的 App 介绍](https://apps.apple.com/cn/app/id952059546)用于核对读听、笔记、历史及 AI 模块。并非已经逐屏核实其全部功能。

当前版本保留书架、发现、阅读器、TTS 听书、个人笔记、进度、阅读数据、AI 辅助及运营管理的规划。独立产品规则如下：

| 项目 | 本期处理 |
| --- | --- |
| 会员或书币 | 不以会员限制私人 TTS，不套用微信读书会员／书币价格；按书借阅／购买 |
| 书籍来源 | 私人文件由读者导入；公共书库由管理员录入版权方授权书或公版书 |
| 公开评分与书评 | 不开放；个人评分、评论和点评仅本机，书籍详情不展示聚合评分或公开讨论 |
| 真人有声书 | 不纳入本期，不提供真人音频上传、购买或播放模块 |
| 关注、好友动态、榜单 | 不默认采集私人阅读数据构建公开关系链；公共社交／好友榜是否延后由用户确认，目前不作为首发实现前提 |
| 发现与推荐 | 先使用管理员书单、分类、新上架及显式兴趣；不上传私人书目或点评来做推荐 |
| AI／OCR | 保留目标能力；默认本机处理。私人正文如需交给外部处理，必须另行确认是否属于本期允许范围，未确认前不发送 |

移动端建议“书架、发现、听书、我的”，桌面端采用侧栏和双栏，个人笔记从书籍／个人中心进入。管理后台是内部 Web 工具，不是第五个消费端。

## 3. 角色与数据边界

| 角色 | 能做什么 | 不能做什么 |
| --- | --- | --- |
| 本地读者／游客 | 本机导入、阅读、TTS、评论点评；连接本人私人云需云账号授权 | 不向公共书库提交内容，不交易未登录权益 |
| 注册读者 | 公共书库借阅／续借／购买、恢复交易权益、设备管理；本人云同步 | 不自助公共上架，不公开评论 |
| 版权方 | 提供有效权利材料、收款资料、借期与借阅／续借／购买价格，获得分成报表 | 当前无自助上架权；不能查看读者私人书库、进度或点评 |
| 内容管理员 | 录入、核查、公版判定、配置定价、发布、下架、处理权利投诉 | 不因管理员身份获取用户私人云或本机内容 |
| 财务管理员 | 对账、分成、结算、退款与争议处理，留痕操作 | 不读取私人正文或评论；不能直接修改已记账流水 |
| 系统管理员／客服 | 按职责管理权限、账号和故障／工单 | 不默认收集正文、云令牌、解密密钥或个人阅读记录 |

私人云由用户所有和控制，不是平台运营的“私有桶”。平台只保存公共书库、账号、交易权益、财务和必要安全日志，不存私人书籍、个人进度、个人笔记及本地评论。详细分类见系统设计的数据位置矩阵。

## 4. 内容与权益模型

### 4.1 作品与版本

作品、译本／版本、文件及授权分开记录。公版判断针对具体版本和适用地区；历史古籍原文可以作为公版候选，例如《道德经》，但具体译注、封面、排版或现代整理成果不能只因原文古老就自动视为公版。此为审核要求，非对某个文件作法律认定。

私人导入不能“一键转公共”。管理员通过独立公共入库流程获取版权方材料或公版来源，不复用读取个人云的权限，也不按私人文件哈希去关联读者身份。

### 4.2 权益矩阵

| 类型 | 获取方式 | 读／TTS 听 | 离线 | 续期 | 原文件导出 |
| --- | --- | --- | --- | --- | --- |
| 私人导入 | 本人本地／私人云 | 不设会员／平台购书门槛 | 支持，本机加密存储 | 不设借期 | 原始来源文件仍归用户控制；App 不额外导出版权明文 |
| 公版版本 | 书城免费获取 | 免费 | 自动下载，App 缓存默认加密 | 不需要 | 保留免费、可用的通用格式下载／导出路径，不用专有加密包锁住公版 |
| 版权借阅 | 版权方定价，可为 0 | 有效借期内可读听 | 自动下载受控加密包 | 次数不限，每次按当次报价完成支付或零元确认 | 不提供明文导出 |
| 版权购买 | 按版权方售价购买 | 依已购权益可读听 | 自动下载受控加密包 | 不作为借阅重复收费 | 不提供明文导出 |

所有公共版权书的上架授权需覆盖本产品拟提供的购买、借阅、TTS 和加密离线能力；缺少能力授权时不把该版本作为满足本产品规则的完整商品发布。私人 TTS 不通过平台商品许可系统收费或封禁；无法解析的 DRM／损坏文件需明确报错，不破解第三方 DRM。

### 4.3 借阅与续借

- 不设全平台或单书数字副本数量、每人同时借阅本数、排队或预约保留流程。技术限流用于防滥用，不可变相引入借书本数上限。
- 版权方配置每次借期、首次借阅价格、续借价格及币种；均可免费。平台不再默认 14 天或限制续借次数。
- 报价明确显示版本、借期、起止规则、价格、税费、是否免费和条款；提交时固定报价快照。
- 每次续借独立确认。建议不默认自动续借或静默扣款；用户明确授权的自动续借机制另行确认。
- 建议有效期内续借从现有到期时间顺延；到期后续借从权益重新生效时间起算。旧时段不追溯补收；定价改变仅影响新确认的交易。
- 重复网络请求不得重复扣款或重复延长借期；显式另一次续借可以新建交易。已有有效借阅时提示“继续读／续借／购买”，不诱导重复首借付款。
- 到期仅停用平台借阅的正文及 TTS 解密能力，保留个人笔记、评论和书架记录；无限续借不是到期后可继续免费解密。
- 归还为终止借阅操作，不释放库存；是否支持已付借期退款按待确认退款政策执行，不能默认承诺自动退款。

### 4.4 购买与售后（部分待确认）

建议购买授予该版本长期读听与离线使用权，不等于取得传播或再上架权，不因版权方停止新增销售而随意撤销已购权益。实际合同需明确长期使用、下架后恢复下载与服务终止安排。

借阅期间购买是否抵扣费用、是否包含未来新版、退款窗口、退款／拒付后权益撤销、已离线设备的生效延迟待确认。报价及订单必须明确，不默认升级、订阅或自动扣款。

## 5. 按书交易与 5%／95% 分成

### 5.1 已确认计算口径

分成基数为该笔借阅／续借／购买的收入扣除实际税费与渠道费后的净收入；平台 5%，版权方 95%。不是在用户支付总额上直接分后再让某方承担未说明的费用。

示例：实际收取 100.00、税费 10.00、渠道费 20.00，分成基数为 70.00；平台 3.50，版权方 66.50。该示例只解释公式，不代表任何实际渠道费率。

- 金额以币种最小单位的整数记录；平台份额按约定舍入，版权方取分成基数减平台份额，保证总和相等。舍入规则建议四舍五入，实施前确认。
- 0 元借阅／续借和所有公版获取不发起支付，不生成虚假可结算收入，仍保留必要的权益事件。
- 未实际确认的渠道费先记“预估／待结算”，不能把估算当作版权方最终应收；到款或结算文件对账后校正。
- 不将 OCR、AI、服务器、私人云、汇兑或其他费用偷偷归入“渠道费”；可扣项目及多币种处理须明确约定。
- 退款、部分退款、拒付及不可退渠道费使用原订单关联冲正，不删除旧账，不把所有回滚都当成按相同比例直接扣现金。
- 负净收入、费用大于收入、版权方已结算后的退款处理列为异常／待定政策，不产生未经确认的负额打款。

### 5.2 交易闭环

详情选借／买／续 → 确认报价 → 支付渠道处理 → 平台服务端验证 → 权益发放与账务事件 → 自动下载 → 对账 → 版权方可结算余额 → 打款 → 结算报表。

支付回调延迟显示“确认中”，不能只凭客户端“成功”开权，也不能在重试时再次扣款。跨端恢复购买使用服务端交易权益，不依赖私人云中的可改文件授予购买资格。

移动端支付须按发行地区和渠道规则设计，不预设所有 App 都能用同一外链支付，也不把平台只收 5% 理解为应用商店只收 5%。以发行时规则为准：[Apple 审核指南](https://developer.apple.com/app-store/review/guidelines/)、[Google Play 支付政策](https://support.google.com/googleplay/android-developer/answer/9858738)。具体收款渠道、结算周期、税务角色及收款主体待确定。

## 6. 私人云、跨端传递与读听续接

### 6.1 私人存储

- 私人书籍、封面、索引、正文、TTS 缓存、进度和可同步个人笔记保存在本机或用户选定的 OneDrive／iCloud；不经过平台服务器暂存、代理、OCR 或云合成。
- 云连接为可选；无云账号不阻止本机读听。用户自己的云容量及费用由云服务条款管理，平台不据此销售私人听书解锁权。
- 默认导入后仅本地保存；用户连接云并启用书籍同步后，自动上传加密包，其他本人设备按同步设置接收。
- 云凭据与恢复密钥不上传平台；平台不收集私人文件名、内容哈希和私人书目清单做去重或推荐。
- OneDrive 与 iCloud 均为首批目标。同一书库建议选一个主同步源；跨云自动双向镜像不是已确认需求，先提供显式迁移及校验，不能制造双主覆盖冲突。
- iCloud 四端路径必须专项验证；不能仅有 iOS／macOS 同步就声称 Android、Windows 已支持。验证失败应报告阻塞，不能未经用户同意以 OneDrive 替代 iCloud 要求。

### 6.2 统一读听位置

进度绑定相同文件／版本与结构化位置（章节、段落、句子、字偏移；PDF 为页与文本锚点）。阅读转听书从当前位置附近的准确句子开始；听书转阅读显示最近已播放到的句子，不按全书百分比粗略推算。

各端通过私人云同步最近有效读听事件，保留“最近位置”和“最远读到”两种数据；听书回放和重读不会被自动跳回最远处。并发修改保留两条续接选项，由用户选择，不单凭设备时钟或最大百分比覆盖。

TTS 音色、语速导致时长变化，跨端续接依文本锚点，不直接复用秒数。扫描 PDF 无文本时仍可看，听书需本机 OCR 或可读文本，明确显示限制。

### 6.3 评论、点评与笔记

- 个人评论、点评、个人评分仅本机保存；无公开、上传平台、私人云自动同步、聚合评分、点赞或回复入口。
- 划线、书签与个人笔记保持私密，是否跟随私人云同步由用户开关控制；与“仅本地点评”分开存储。
- 各类数据分类、导出和删除分开处理；用户主动本地导出是显式操作，不能变成自动上传。

## 7. 默认下载、加密与离线

1. 获得公版／借阅／购买权益后默认自动下载；私人云书籍同步到新设备也按设置自动取回。提供蜂窝网络、仅 Wi-Fi、空间不足、暂停重试与缓存清理设置。
2. “离线可用”仅在正文、资源和有效授权均下载并校验完成后显示，不能把下载开始当作离线完成。
3. App 管理的正文、派生内容、检索索引及 TTS 临时数据默认加密。版权内容不创建用户可直接打开的解密 EPUB／PDF／TXT，也不以分享、备份、日志或临时目录泄露整书。
4. 公版缓存也可默认加密，但仍提供免费通用格式导出，不把公版内容变成只能在 App 内打开的收费商品。
5. 用户先前持有的私人原始文件不被 App 自动删除或改写；平台加密不能使用户已持有的明文“消失”。
6. 离线借阅许可证不得晚于借期失效；时钟异常和设备重置需要明确恢复流程。购买长期离线验证策略及最长离线窗口待确认，不直接套用旧稿的每 24 小时联网限制。
7. 离线退款／撤销无法瞬时通知断网设备，须明确可接受延迟。到期判断、密钥安全与真机攻击测试是发布门槛。
8. 加密目标是阻止普通文件访问、跨账号复制和未授权明文导出；不能承诺对已破解设备、内存抓取、截图／拍照实现绝对防盗版。若授权要求商业 DRM，应验证四端 SDK 与成本，而不是自行宣称不可破解。

## 9. 格式、平台与商用品质

- 格式：无 DRM TXT、EPUB 2／3、PDF；EPUB 保留图片、目录、脚注与安全 CSS；PDF 保留原版式；扫描件 OCR 能力单列，不破解第三方保护。
- 不再规划真人音频文件上传；书籍单文件 100 MB 作为暂定安全处理上限，不代表云容量配额。用户私人云容量以其账户为准，平台不分配“2 GB 私人云”。
- 建议最低系统：iOS 15、Android 8、Windows 10 x64、macOS 12；含平板。Intel Mac／Windows ARM64 和具体插件组合需验证再承诺。
- 初始压测建议：1 万日活、1,000 活跃读听会话、200 次/秒平台业务请求；私人云流量不计入平台正文中转吞吐。
- API 在基准负载 p95 ≤500 ms、5xx <0.5%；缓存章节 ≤1 s；目标设备冷启动 ≤3 s；长书与连续两小时听书无持续内存增长；均为待验证目标。
- 生产 API 月度可用性目标 99.9%；平台数据库 RPO ≤24 h、RTO ≤4 h 需恢复演练。平台备份不含用户私人云，私人恢复由加密快照和用户恢复密钥承担。
- 权益与账务：重复支付回调、乱序退款、跨端同时续借不得重复收款或重复发权；比例与最终实收可对账。
- 隐私：私人正文、进度和本地点评不得出现在平台数据库、日志、分析 SDK 或崩溃报告；不以“脱敏”替代不上传。
- 安全：越权、密文篡改、密钥泄露、时钟回拨、离线到期及跨账号复制均有测试证据。
